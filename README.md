# experiment3
软件工程实验三：面向对象的系统建模A

## 实验内容
本仓库包含实验三的所有代码与UML类图，分为四个部分：
- `A1-1_Thoroughbred`：优良品质的马（自关联建模）
- `A1-2_College`：学院、建筑与课程（聚合、组合与约束注释）
- `A1-3_School`：学校、系、教师、学生与课程（多重性关系）
- `A1-4_Shopping`：简化网上购物系统（泛化与组合关系）
- `diagrams`：存放上述四道题的 UML 类图截图（PNG格式）

## 实验环境
- 建模工具：ProcessOn
- 开发语言：Java (JDK 17)
- 版本控制：Git & GitHub

## 如何运行代码
进入对应的子文件夹（如 `A1-4_Shopping`），执行以下命令：
```bash
javac -encoding UTF-8 *.java
java Main
